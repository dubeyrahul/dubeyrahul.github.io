CLAUDE.md — working context for this repo

Local-only notes (gitignored). Purpose: let any future Claude/Claude Code session pick up where we left off. Not published, not pushed.

What this repo is

Personal blog + portfolio for Rahul Dubey, built with Quarto, deployed to GitHub Pages.

  • Source of truth: main branch (.qmd, _quarto.yml, styles.scss, posts/).
  • Build output: docs/ (gitignored, local preview only).
  • Live site is served from the gh-pages branch, published via quarto publish gh-pages (builds and pushes to gh-pages). No GitHub Action.
  • URL: https://dubeyrahul.github.io/ (custom domain dubeyrahul.com planned, not bought yet)

Local workflow

  • Preview: quarto preview (live-reload at http://localhost:xxxx)
  • Render only: quarto render
  • Deploy: quarto publish gh-pages

The North Star

Rahul is a Senior ML Engineer (Patreon; prior Amazon, Lyft, Yelp) focused on ranking / search / recommendations. Long-term goal: build the blog/portfolio into something that credibly positions him as an AI/ML consultant for eventual freelance work. Strategy = show experience + knowledge, build a consistent body of work.

Author preferences (important)

  • No internal/proprietary metrics on the public site. Company names are fine. UUUPAR is a public-safe project name.
